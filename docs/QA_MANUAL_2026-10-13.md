| 在建项目数 | 状态为「进行中」的项目数 = 2 | 项目管理按状态筛 |
| 风险项数 | 点开应能分解成是哪几项 | 逐条点进去看是不是真的 |

**特别注意**：排行里**不该**出现 005/006/007 那种「有合同额、零支出 → 算出来毛利率 100%」的项目。它们被有意剔除了（只录了合同额没录支出，100% 纯属假象）。如果你看到榜首有个 100%，那是回退了。

7. 填 `abc` → 应被拒「应为数字」；日期填 `2026-02-30` → 应被拒「应为有效日期」
8. **⚠️ 这条最容易踩**：某项目已填好 4 个字段值，你打开表单后**删掉**其中一项再保存 → 那个字段会被写成空。设计口径叫「未提交即清空」。判断一下这个行为在业务上是否可接受
9. 回 **项目管理** 列表：按自定义字段筛选（如「复尺日期在某区间」），验证筛出来的项目对不对；单选字段的多选取一个值筛

### D4 主题切换与 Logo

1. 顶栏「设置」→ 主题四选一（钴蓝/铁锈红/翠绿/青碧）。逐套切，每套都刷新看**全站**是否都变了（首页、报价、驾驶舱、日历、抽屉、主按钮）
2. 重点看**青碧**这套：主按钮上的字应是**深色**而非白色（浅青底白字对比度会塌，专门为它加了一个前景令牌）。如果青碧套的主按钮字发飘看不清，就是回归了
3. 每套下都开一次报价打印预览，看 accent 是否仍守「单点强调」，有没有满屏变彩色
4. Logo：上传一张 `.svg` → 应被拒「仅支持 PNG / JPG / WebP 格式」；上传一张超过 512KB 的 png → 应被拒「图片过大…」；正常上传 → 左上角应换成你的图；「移除 Logo」→ 应回到默认文字标
5. 系统里打开「减弱动态效果 / 减少动效」开关（Windows：设置 → 辅助功能 → 视觉效果 → 动画效果关闭），刷新页面重开抽屉 → 滑入动画应几乎消失但**状态仍可辨**（这是 M9-e 刚补的可访问性硬要求）

## 6. 破坏性操作速查（会删真数据、界面上无法反悔）

| 操作 | 位置 | 后果 |
|---|---|---|
| **保存报价** | RP-2026-001 报价编辑器 | 整表替换：页面上没有的行，库里就没了 |
| **确认签约** | 商务线索 | 永久建出客户 + 项目 + 草稿报价单，无解约入口 |
| **确认清空**排程 | 时间管控 | 删本项目全部工序与依赖；已生成的验收节点不会跟着删，可能成孤儿 |
| **确认删除**字段 | 自定义字段 | 连带删掉所有项目上该字段的已录值 |
| **删除变更** | 变更单页 | 硬删，三处汇总数字立刻回落 |
| **删除此记录** | 财务台账 | 硬删，无回收站 |
| **确认清空**付款计划 | 付款计划页 | 不可撤销（但已付段会被守卫挡住，清不掉） |
| 删除科目 | 科目库 | 连带删该科目下全部科目项（历史报价是快照，不受影响） |
| **应用主题 / 上传替换 Logo** | 设置 | 全站生效 / 覆盖旧 Logo 文件（可再改回，不算高危）|
| **归档项目 / 作废线索** | 项目列表·项目详情·线索列表 | **可逆**（M10-a）：只从统计口径里摘出去，数据保留，可恢复；不再是"删了就没了"的高危操作 |

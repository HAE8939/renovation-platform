## 1. 三条落地口径（决策，已入册 `AGENTS.md` §4.3 / §4.4 / §4.5）

1. **归档 ≠ 删除**。只翻可见性位，报价/台账/节点/流水一行不动，随时可恢复；平台不设硬删除入口。
2. **恢复要回到归档前那一态**，原值取 `OperationLog.before`（存**机器值** `in_progress`，中文态名进 `summary`）。恢复动作不许一律塞回 `draft`。
3. **流水埋点在动作层，不在服务层**。服务函数普遍包在 `prisma.$transaction` 里，日志一旦进事务，记流水失败会连业务写入一起滚掉——违反"流水 best-effort"。
4. **已签约线索不许只作废线索**（会切断 `Lead.projectId` 这条 1-1 来源，见 §4.1）；要清掉走项目归档。守卫在服务层 `setLeadArchived`，界面不重复判断。
5. **主题插槽现在有两份声明**（根级管全站换肤 + 元素级管组件内局部预览），两处必须同键集合同值，`verify-theme` 新增双声明锁。

**本轮抓到并修好的真缺陷两条**：

1. **恢复项目落回 `draft` 而不是原状态**——流水的 `before` 格我一开始存了中文态名「施工中」，恢复时拿它去 `isProjectStatus()` 校验失败、静默回落 `draft`。一格两用是根因；改法：`before` 存机器值，中文态名进 `summary`。**纯函数与 build 都拦不住，只有真点一遍才暴露**——正是 §4-7 那批代验存在的理由。

## 6. 追加：M10-b 启动页首屏（同日第二批，HAE 选「完全例外」）

HAE 要"高大上的启动页"，而这正撞 V0.3 §Benchmark ≠ Style 红线（明令禁止把高级理解成大标题+黑底+巨图+滚动动画）。给了三个方案，HAE 选 **启动页完全例外、不受 V0.3 管**。落地方式是把例外**成文并关进笼子**，而不是口头破例（已入册 `AGENTS` §6.3）：

- 实现：`src/app/HeroSplash.tsx` + `globals.css` 的 `.splash-*` 段。运动逻辑取自 codex 模板的拆解表（120ms 起、标题 240ms/720ms `cubic-bezier(.22,.61,.36,1)`、副标题 470ms 起逐字 42ms、CTA 1180ms、底部提示 1.5s 脉冲），**文字与配色全换成平台自己的**（纸底 + 当前主题 accent 族，深色按钮用墨色变量 `#2B2A26`，未引入任何新色值）。
- 三条不豁免的约束：例外只锁 `.splash-*` 作用域（业务页引用即越界，`s10` 有防外溢断言）；配色必须吃 CSS 变量（切到青碧时首屏强调色实测从 `rgb(42,78,122)` 变 `rgb(10,118,128)`）；`prefers-reduced-motion` 必须支持（脚本跳过逐字、全局规则压时长）。
- 首屏是 `fixed` 覆盖层，收起（滚轮 / 进入平台 / Esc）后就是原来的模块索引页，DOM 结构未变，回归面为零。
- **文案第二轮（HAE 2026-10-13 18:0x）**：主标题改「**一站式数字管理平台**」（「一站式」上 accent 做全画面唯一强调点），eyebrow 随之从「装修经营 · 数字化管理平台」改成「装修经营 · 全流程数字化」——否则与标题重字。CTA 两颗定为「**进入平台**」+「**平台说明**」。

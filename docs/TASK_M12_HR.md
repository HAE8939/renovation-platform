# M12-a 人员工控首期规格

## 目标

把“谁在什么项目承担什么责任”做成共享主数据，为排程负责人、质量责任人、工作记录和后续绩效汇总提供唯一来源。首期不做登录、薪资、考勤打卡或自动评分。

## 首期范围

- 人员档案：复用 `core/domain.User`，展示姓名、岗位、部门、邮箱和当前项目数。
- 项目责任关系：新增 `ProjectMember`，以 `projectId + userId + role` 唯一；角色先覆盖项目经理、设计师、工程巡检、施工负责人、项目协调。
- 责任关系维护：人员工控页可添加和移除关系，动作写入 `OperationLog`。
- 归档口径：归档项目不进入人员工控的在用项目和责任列表，历史关系随项目保留。

## 后续批次

1. 工作记录：日期、项目、人员、事项、工时、产出链接，先做事实采集，不做评分。
2. 项目责任确认：在项目详情页显示责任矩阵，并支持负责人确认。
3. 绩效汇总：先按已记录事实统计项目/月份维度，再由业务确认指标后设计评分。
4. 登录与权限：P4 接入后把当前占位用户替换为 session userId，沿用现有字段。

## 验收口径

- 不复制 User 或 Project 的名称字段。
- 人员工控页没有人员或责任关系时显示诚实空态。
- 删除关系只删除关系记录，不删除人员、项目或业务流水。
- `pnpm build`、TypeScript 检查和迁移通过。
